# 更新日志

本文件记录面向使用者的版本变更。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [1.0.5] - 2026-11-13

界面文案规范化。

### 变更

- 全站界面说明改为书面表述，去掉口语化与教程式说法；必要的操作说明保留，改用「动作 + 对象 + 结果」的陈述句。
- 术语统一：界面中的「手牌 / 手牌区」改为「待部署区 / 干员」，「已放下」改为「已放置」。
- 修正干员朝向环位置的描述（位于头像左上角）。
- 同步更新配队分享文案、README 与使用说明。

### 说明

- 1.0.1–1.0.5 均未改动数据，数据版本保持 2026-11-11。
- 每个补丁对应一个开发轮次（第三十八至第四十一轮；阿戈尔结算修正单独计一个补丁）。
- 本发布目录为 1.0.5，已包含 1.0.1–1.0.5 的全部内容。

## [1.0.4] - 2026-11-13

阿戈尔盟约「吞噬」结算修正。

### 修复

- 每名已激活的阿戈尔都从自身出发沿「身前一格」连链结算，不再因自身已被他人吞噬而跳过。
- 同一目标可被多名阿戈尔同时吞噬：每个吞噬者均保留吞噬标记，层数仍按目标只计一次，日志来源列出全部吞噬者。
- 「更靠左、再靠上」的优先级仅用于两名阿戈尔相互吞噬（A⇄B），后手不再反吃。
- 叠层事件新增吞噬者列表字段，用于记录同一目标的全部来源。

## [1.0.3] - 2026-11-13

沙盒操作增强。

### 新增

- 卡牌仓库中的干员可直接拖入战场部署，不经过待部署区，默认为普通形态。
- 「归零」按钮：一次清空全部盟约的固定层、临时层、每回合 / 每场 / 总层数上限计数与层数事件。

### 修复

- 归零后「补满叠层」可重新结算，不再受旧计数器影响。

## [1.0.2] - 2026-11-12

### 修复

- 沙盒地形标记（终点、侵入点、特殊高台、沼泽等）不再盖住干员头像。

## [1.0.1] - 2026-11-12

沙盒卡牌仓库筛选改版。

### 变更

- 去掉与分组「清除」重复的「清筛选」按钮；「只看配队」改为「只显示配对码干员」。
- 筛选面板顶部新增「清除全部」，一次清空搜索、阶数、盟约、触发时机与配队码筛选。
- 盟约筛选不再使用二级滚动条，整个面板只保留一条滚动条，并随视口自适应高度。

## [1.0.0] - 2026-11-12

首个正式发布版本。

### 新增

- **图鉴**：干员 / 道具 / 策略 / 盟约四类词条，支持搜索、别名索引、多维筛选与深链分享。
- **干员详情**：普通 / 精锐形态、售价、盟约、触发时机；另有自选干员档案与特殊干员补充信息。
- **敌人图鉴**：189 条敌人（179 普通 + 10 领袖），支持名称与 ID 搜索、词条组合筛选、
  「难度 + 回合」数值换算；战场地图可查场地、地形、装置与适用难度。
- **模拟配队（BETA）**：8 人配队、盟约自动点亮、叠层上限统计、共享码与配队一图流。
- **沙盒叠层（BETA）**：规程战场摆位与朝向、逐事件叠层、日志 / 诊断导出、`GSPS1` 沙盒码。
- 深色 / 浅色主题、移动端适配、头像与图标显示开关。

### 说明

- 数据版本：2026-11-11（卫戍协议·规程，官方 Android 热更新 26-11-06 解包）。
- 纯静态站点：无后端、无账号、无第三方统计，仅使用浏览器本地存储保存界面偏好。
- 本版本以目录形式发布，同时附带可离线双击打开的单文件版 `standalone.html`。
