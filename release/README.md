## 约定

- 目录名 `GSPA-<语义化版本>`，与 git tag `v<版本>` 一一对应（如 `v1.0.6`）。
- 每个版本目录至少包含 `README.md`、`CHANGELOG.md`、`VERSION`、`LICENSE`、`NOTICE.md`。
- 发布产物由 `dist/` 整理而来：保留运行所需文件，剔除构建说明、调试数据与测试内容。
- 历史版本保持只读；修复请发布新版本，不原地修改已发布目录。
