# 发布版本（Releases）

本目录按版本存放可直接部署的静态站点，每个子目录都是一个自包含的发布产物，
不包含构建日志、测试脚本、开发文档与数据源表。

| 版本 | 发布日期 | 数据版本 | 说明 |
| --- | --- | --- | --- |
| [GSPA-1.0.0](GSPA-1.0.0/) | 2026-11-12 | 2026-11-11 | 首个正式版：图鉴 / 搜索 / 筛选 / 敌人图鉴 / 配队（BETA）/ 沙盒（BETA） |

## 约定

- 目录名 `GSPA-<语义化版本>`，与 git tag `v<版本>` 一一对应（如 `v1.0.0`）。
- 每个版本目录至少包含 `README.md`、`CHANGELOG.md`、`VERSION`、`LICENSE`、`NOTICE.md`。
- 发布产物由 `dist/` 整理而来：保留运行所需文件，剔除构建说明、调试数据与测试内容。
- 历史版本保持只读；修复请发布新版本，不原地修改已发布目录。
